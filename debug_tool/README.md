# 🎙️ Realtime 实时语音提示词本地调试工作台 (Prompt Debugger)

本目录是一个**完全独立于手机 App** 的轻量级本地调试工作台，专为在 PC 电脑上快速迭代测试百炼 `qwen3.5-omni-flash-realtime` 实时语音提示词设计。

---

## 🚀 启动方式

### 方式 1：Windows 双击一键启动（推荐）
直接在文件资源管理器中双击运行本目录下的：
👉 **`run.bat`**

### 方式 2：命令行启动
打开终端（PowerShell 或 CMD），进入本目录并执行：
```bash
python server.py
```

服务启动后，会自动打开您的默认浏览器并访问：
👉 **`http://127.0.0.1:8765`**

---

## ✨ 核心调试功能

1. **大文本框实时编辑 Prompt**：
   - 包含苏格拉底、反方辩友、研讨伙伴、一年级助教、十万个为什么及自定义角色；
   - 随意修改提示词文本，随时点击「开启实时连麦通话」即可毫秒级生效，再也不用重新打包 APK！

2. **时长与语速三大硬核控制策略**：
   - **字数硬刹车**：自动把输入的秒数折算为严格的字数上限（如 10 秒对应限制 35 字以内，严禁超过 2 句，讲完即止）；
   - **呼吸标点法（专治语速过快）**：强制在短句间高频加入逗号与省略号“……”，人为拉大字间停顿，制造幼儿故事般的从容慢速感；
   - **反废话拦截**：坚决禁止模型打招呼寒暄或发散铺垫，直奔核心主题。

3. **精准测速与质量监控面板**：
   - ⏱️ **本次 AI 讲话耗时**：实时跳动高精度秒表，统计 AI 实际发音秒数；
   - 📝 **回答字数统计**：提取模型输出文本自动数汉字；
   - ⚡ **实际发音语速**：计算真实语速（字/秒）；
   - 🎯 **遵从度评估**：与设定的目标时长自动比对，超标或偏短一目了然！

4. **一键同步到手机工程**：
   - 在本网页中调试出最满意的提示词后，点击左下角的 **「📋 复制为安卓 Kotlin 代码」**，直接粘入 Android Studio 即可！
